1. Executive Overview & Mission

Project LOOP is a corporate-grade, multi-tenant B2B SaaS feedback intelligence engine that unifies customer feedback across fragmented channels (Support Tickets, App Store reviews, NPS surveys, Sales calls, and Intercom chat logs).

Unlike conventional sentiment analysis tools that produce superficial word clouds, Project LOOP combines deterministic quantitative analytics with grounded LLM intelligence (Google Gemini 2.5 Flash + text-embedding-004 vector embeddings) to ensure zero hallucination, theme spike detection, and verbatim quote citations.

3. Architecture & Security Guarantees

1. Cryptographic & Logical Multi-Tenancy

  • Every database query strictly filters by WHERE workspaceId = session.user.workspaceId.
  • Cross-tenant leakage is mathematically and logically impossible.
  • NextAuth session cookies carry immutable workspace claims verified on every request.

2. Zero-Hallucination Grounded AI

  • Gemini prompts strictly enforce refusal if customer quotes are not present in the workspace corpus.
  • Every answer cites bracketed source quote IDs [1], [2].
  • Quantitative metrics are pre-calculated deterministically in TypeScript before narrative generation.
